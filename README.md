# Kai Tara — Horoscope & Astrology

Telegram-бот ведической астрологии (джйотиш): [@KaiTaraAstroBot](https://t.me/KaiTaraAstroBot).
Русский и английский.

## Возможности
- Прогноз на новолуние/полнолуние для знака (по Луне, сидерическому или привычному знаку Солнца)
- «Сегодня»: накшатра, титхи, вара, личные тара-бала и чандра-бала, утренняя рассылка
- Календарь благоприятных дней (упрощённая мухурта) на 30 дней по 7 темам
- Совместимость пар по ашта-куте (36 баллов, нади- и бхакут-доши)
- Большие транзиты: смена оси узлов (средний и истинный узел), Юпитер, Сатурн — с пушами
- Натальная карта: картинка в южноиндийском стиле и таблица планет; PDF-разбор карты
- Словарь из 92 терминов: любое слово в прогнозе кликабельно
- Поиск города по названию (офлайн, GeoNames: Россия и СНГ от 1000 жителей, мир от 15 000)

## Приватность
Дата, время и место рождения **не хранятся**: при регистрации бот вычисляет астрологический профиль
(знаки, накшатра Луны, даши с точностью до месяца) и забывает ввод. Для натальной карты данные
держатся только в оперативной памяти не дольше 30 минут.

## Устройство
```
jyotish/   расчётное ядро на Swiss Ephemeris: позиции, накшатры, даши, гочара, события,
           панчанга дня, мухурта, ашта-кута, профиль, анализ карты, тексты (ru/en), поиск городов
bot/       aiogram 3 + asyncpg: обработчики, i18n, оплата Telegram Stars (выключена: FREE_MODE),
           рассылки, PDF (reportlab), картинка карты (Pillow)
migrations/  SQL-миграции, применяются ботом при старте
deploy/    systemd-юнит и установщик для Debian/Ubuntu
tests/     pytest: ядро и сквозные сценарии бота на встроенном PostgreSQL (pgserver)
tools/     сборка базы городов из GeoNames, экспорт публичной копии
```
Параметры: сидерический зодиак, айанамша Лахири, дома по целым знакам, Вимшоттари-даша,
средний узел Раху/Кету (истинный — для дат смены узлов).

## Запуск
```bash
python -m venv .venv
.venv/bin/pip install --upgrade pip setuptools wheel   # старый setuptools ломает сборку pyswisseph
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN, DATABASE_URL, ADMIN_IDS
.venv/bin/python -m bot.main
```
На сервере: `sudo bash deploy/install_vds.sh` (ставит PostgreSQL, шрифты, venv, systemd-сервис).

Тесты: `pip install -r requirements-dev.txt && pytest -q tests`.

CLI ядра: `python run_forecast.py`, `python run_forecast.py --chart "1980-05-14 06:30" --city spb`.
